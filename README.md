# KrishiMitra AI

A voice-first, multilingual farming assistant: crop and pest advice, sustainability guidance and farm business ideas.

## Tech stack

React, TypeScript, Vite, Supabase Edge Functions (`chat`, `translate`, `tts`, `weather`, `generate-business-image`)

## Run locally

```sh
npm install
npm run dev
```

Backend features need a Supabase project; set `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`.

See `TROUBLESHOOTING.md` and `IDEATHON_PITCH_NOTES.md`.
